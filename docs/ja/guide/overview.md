# RMC 法と RMC_POT

Reverse Monte Carlo（RMC）法は、散乱実験などで得られたデータに整合する三次元原子配置を構築する手法です。原子配置から計算した散乱量と測定値との差を評価し、原子位置の試行変更を反復します。

RMC_POT は、中性子回折の $S(Q)$、X 線回折の $F(Q)$ や $I(Q)$、電子回折の $F(g)$、EXAFS の $E(k)$ などを扱います。部分二体分布関数 $g_{ij}(r)$ は、原子配置から得られる重要な構造量です。

散乱データだけでは局所構造が一意に決まらない場合があります。そのため、必要に応じて原子間距離、配位数、結合角、FNC、その他の構造制約を組み合わせます。

RMC_POT の計算を始めるには、初期原子配置、計算条件、および使用する実験データを準備します。各ファイルの役割は [入力ファイル](input.md) にまとめています。

詳しい理論は [RMC 法の解説](../reference/rmc_theory_explained.md) を参照してください。
