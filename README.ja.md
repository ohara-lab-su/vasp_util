# vasp_util

[![en](https://img.shields.io/badge/lang-en-red.svg)](https://github.com/ohara-lab-su/vasp_util/blob/main/README.md)
[![ja](https://img.shields.io/badge/lang-ja-yellow.svg)](https://github.com/ohara-lab-su/vasp_util/blob/main/README.ja.md)

世の中に山のように存在する、VASPを便利に使うためのツールの一つです。

もともとは [RMC-DFT](https://github.com/ohara-lab-su/rmc_dft/) の内部で使っていた VASP 関連の処理を、ほかのプログラムからも利用できるように切り出したものです（0.7.10 から分岐）。

ASE や pymatgen には、構造の生成・変換から各種解析まで、すでに非常に多くの機能があります。今さら同じものを一から作り直しても仕方がありません。`vasp_util` で扱いたかったのは、VASP の構造や計算結果を取り出した後、実際の研究で必要になる解析です。既存のライブラリを調べても目的の処理がそのまま見つからなかったため、必要な部分を個別に実装してきました。

もちろん、一般的な入出力や座標操作まで含めて、すべてが独自の機能というわけではありません。これらは解析を組み合わせるための共通部分として用意しています。ASE・pymatgen で足りる処理はそれらを使えばよく、実際に両ライブラリを利用している箇所もあります。将来、内部実装や上位 API としての連携を整理する場合も、既存の機能を重複して作ることが目的にはなりません。

## 開発の経緯

2010年頃から2015年頃にかけて、[sae](https://github.com/ohara-lab-su/sae) という、VASP を始めとした結晶構造関連のツールを開発していました。当時蓄積したノウハウが、現在のツール群の基礎になっています。

ただ、sae は機能を追加するうちに巨大化し、当時の私自身の Python に対する理解不足もあって、設計面でいろいろと問題を抱えていました。その後、pymatgen や ASE が非常に便利になり、sae 自体の存在意義も薄れたため、長いことお蔵入りになっていました。

それでも VASP を使ったツールを作っていると、特に POSCAR の構造を扱ったり、計算結果から必要な情報を抽出したりする場面で、手元に共通の処理が欲しくなることが度々ありました。個々のプログラムで必要な部分だけを実装しているうちに、似たようなコードがあちこちに増えてしまいました。

sae 全体を再設計するのは負担が大きいため、まず RMC-DFT の内部に、実際に使う機能を小さなクラス群としてまとめました。それらを独立したパッケージにしたものが `vasp_util` です。

## 扱っている処理

現在は、POSCAR の格子・原子座標の読み書きと変換、周期境界条件を考慮した原子間距離・近接原子・原子移動の解析、INCAR・KPOINTS の編集、POTCAR の組み立て、OUTCAR からのエネルギー・力・磁気モーメントの取得、VASP の実行・ログ管理などを扱います。RMC-DFT から切り出した経緯から、RMC と VASP の構造データの受け渡しも含まれています。

このうち、ファイルの読み書きや基本的な座標操作は解析の土台です。ライブラリとして重点を置いているのは、そこから先の構造・計算結果の解析処理です。ただし、どの解析が ASE・pymatgen やその周辺パッケージに存在しないかは、機能名だけで決められません。計算する量、原子の追跡方法、周期境界の扱い、解析条件まで含めて比較する必要があります。

[ドキュメント](https://ohara-lab-su.github.io/vasp_util/) には使用例と API リファレンスを掲載しています。API リファレンスはソースコードから抽出したシグネチャ・docstring 等も利用しています。静的なコード解析による記述と、実データによる動作確認は区別して扱います。
